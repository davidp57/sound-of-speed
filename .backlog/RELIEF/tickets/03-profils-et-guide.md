# 03 — Les profils livrés et le guide

**Statut :** ✅ fait

**Bloqué par :** 01 et 02

## Ce qu'il faut obtenir

Les deux profils livrés ont un relief qui correspond à leur nom, et le guide de
création en produit un selon le tempérament demandé.

- **Route** — une conduite ordinaire : 8 dB entre lever le pied et écraser, 3 dB
  de rugissement qui s'ajoutent aux 4 de la banque.
- **Sport** — exagère l'effort : 10 dB d'écart de charge, 4 dB de rugissement.
- **Le guide** — un tempérament calme reste discret, un sportif exagère, et le
  ralenti d'un sportif est plus effacé.

## Critères d'acceptation

- [x] Sport a plus de relief de charge et de régime que Route
- [x] Le tableau acoustique des six situations est établi pour les deux profils
      et figure dans la spécification du lot
- [x] L'ordre suit l'effort : ralenti < pied levé < croisière < montée douce <
      montée rapide < haut régime
- [x] Le guide déduit les trois valeurs du tempérament, vérifié par un test
- [x] Le README chiffre le nouveau comportement là où il décrit les réglages
